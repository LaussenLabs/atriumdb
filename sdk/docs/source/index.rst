Welcome to AtriumDB
===================

AtriumDB is a complete solution for managing and analyzing physiological waveform data.
It includes an SDK for data compression, storage, and retrieval, a RESTful API for remote access,
and a CLI entrypoint for automating command tasks.

New here? Start with :doc:`Installation <installation>`, then the
:doc:`Quickstart <quickstart>`.

Looking up a method signature? Everything public — ``AtriumSDK``, ``DatasetDefinition``,
``DatasetIterator``, ``Window``, ``transfer_data`` — is in the
:ref:`API Reference <api_reference>`.

To learn more about AtriumDB, visit the `about page <about.html>`_.
